# Parity archive

Historical planning and evidence for the Windows/Linux parity work, moved out
of [`open-mt2/devkit`](https://github.com/open-mt2/devkit) when the devkit
stopped carrying agent documentation.

| Path | Contents |
|---|---|
| `docs/planning/` | the parity plan, the task sheet, the T0.3 data-width audit and a snapshot of the fixed-function matrix |
| `evidence/` | per-task command output, logs and screenshots (`evidence/<ID>.md` and companions) |

Archived from `open-mt2/devkit` at `1c4b36f` (2026-10-31).

These files are **historical**. Paths inside them refer to the devkit layout at
the time (`evidence/<ID>.md`, `docs/planning/...`, `src/<Package>`). The live
feature matrix now lives at `devkit/docs/feature-matrix.md`; the copy here is
the archived snapshot. Wave B is closed and the only open scope in the sheet is
the deferred Wave 5.
